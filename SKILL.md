## 1. Teknologi & Perangkat Lunak Terpakai
| Area | Spesifikasi / Tools | Kegunaan |
|---|---|---|
| **Backend Language** | PHP Native (PHP 8.x) | Logika sistem, NLP Engine, Security rules |
| **Database** | MySQL | Penyimpanan dataset teks, admin, log |
| **Local Server** | XAMPP (Apache) | Menjalankan server aplikasi web lokal |
| **Frontend** | HTML5, CSS3, Vanilla JS | Antarmuka pengguna dan AJAX Fetch |
| **IDE/Code Editor** | Visual Studio Code | Menulis dan memelihara kode program |
| **Metode NLP** | TF-IDF & Cosine Similarity| Ekstraksi fitur teks dan pencocokan pola |
| **Metode Testing** | Black Box Testing | Validasi fungsionalitas sistem berjalan baik |

---

## 2. Kompetensi Esensial (Best Practices)
1. **Keamanan Backend:** Mampu menerapkan anti-XSS (`htmlspecialchars`), anti-SQLi (`PDO`), dan Validasi File Upload yang ketat di PHP.
2. **Asynchronous JS:** Menguasai API fetch AJAX untuk membuat Chat UI yang *seamless* tanpa memuat ulang halaman (no page reload).
3. **Matematika Dasar NLP:** Memahami alur kerja dan formulasi TF-IDF (perhitungan frekuensi matriks) sebagai fondasi kecerdasan sistem (penting untuk ditunjukkan saat sidang skripsi).
